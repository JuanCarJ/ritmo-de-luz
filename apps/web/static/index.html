03

Qué hace el sistema

El audio no se muestra aislado: controla el aspecto y el movimiento del video.

  1. Entrada: recibe una imagen PNG/JPG y un audio WAV de 20 a 40 segundos.
  2. Base — análisis: divide el audio en ventanas y calcula RMS, centroide, onsets y 12 bandas mel.
  3. Base — normalización: lleva esas medidas a una escala común para compararlas durante todo el audio.
  4. Base — composición: divide la imagen en una cuadrícula 4 × 6 (24 mosaicos); cada una de las 12 bandas se reutiliza en dos regiones para modular brillo, escala y color a 30 frames por segundo.
  5. Base — salida: exporta un MP4 sincronizado y devuelve un enlace para abrirlo.
  6. Extensión opcional — K-Means: agrupa ventanas acústicas y colores para añadir estados visuales. Se activa con ENABLE_ML=true; si no, se usa el resultado determinista base.
